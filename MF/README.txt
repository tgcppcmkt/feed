MyFeed v0.3.0
=============

高速更新 v2
- WEB / RSS / X：最大12フィード並列
- Google News：最大6フィード並列
- Google Newsは記事本文を先に保存・表示
- サムネイル画像はバックグラウンドで後追い補完
- 一括更新時の通信タイムアウトは12秒

継続機能
- 個別フィードのフォルダ変更 / 削除 / 個別更新
- GPT向けTXTエクスポート
- Google News英字キーワードの国内+海外取得
- 72時間キャッシュ / 重複整理 / お気に入り

Edgeへの読み込み
1. ZIPを展開
2. edge://extensions/ を開く
3. 開発者モードをON
4. 「展開して読み込み」で MyFeed-v0.3.0 フォルダを選択

既存版から差し替える場合は、展開後に拡張機能の再読み込みでもOKです。
